# Security Policy

## Reporting a Vulnerability

First off, thanks for taking the time to help keep this project secure! 

If you happen to discover a security issue or a bug in this extension, please **do not** open a public GitHub issue or post about it publicly. Instead, please report it privately so we have a chance to fix it safely before anyone else finds out.

You can reach out privately by sending a message directly through my GitHub profile or by creating a private vulnerability report if enabled in the repository's security tab. 

Thank you for helping keep the code safe and secure!
